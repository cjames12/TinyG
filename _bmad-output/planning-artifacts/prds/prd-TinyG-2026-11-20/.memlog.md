## Key Design Decisions

1. **Touch Targets:** 48 CSS pixels minimum (WCAG 2.5.5); matches brief requirement and standard for toddler apps
2. **Feedback Triple:** Sound + Vibration + Visual (not any single modality) ensures accessibility and clarity
3. **Difficulty Curve:** Automatic round progression; 6 → 7 → 8 shapes; silhouette variations (rotation, size) added gradually
4. **Undo as Built-in:** Mismatch shape returns to start; no separate "undo" button needed; keeps UI simple
5. **No Backend Phase 1:** Fully client-side; zero data collection (parent privacy); session-based (no progress saving)
6. **Phase 2 Gating:** 90% mastery + 2-week engagement before celebration animations and character traits (not feature creep)
7. **Responsive-First:** Phone (375px) → Tablet (768px) → Desktop (1024px+); same interaction on all sizes
