## Discovery Decisions

### Visual Aesthetic
- **Decision:** Playful & colorful energy without overwhelming.
- **Detail:** Balanced mix of saturated primaries + softer tones. Not harsh neon, not all pastels. Warm, joyful.
- **Source:** Parent feedback (balanced energy)

### Layout Strategy
- **Decision:** Truly random scatter across the screen.
- **Detail:** Shapes and silhouettes positioned randomly each round, encouraging exploration. Not in left/right panes. Same on all devices (scales proportionally).
- **Source:** Parent feedback + PRD requirement

### Selection Visual Cue
- **Decision:** Combo — Glow + scale-up together.
- **Detail:** Soft radiant glow + 1.15x scale (or similar) to make selection clear and alive. Instant feedback (no animation delay).
- **Source:** Parent feedback

### Animation Feel
- **Decision:** Smooth + bouncy combo.
- **Detail:** Polished easing (cubic-bezier for smooth motion) + subtle bounce on arrival (overshoot ~1.1–1.15). Match success feedback ~400–500ms, return on mismatch ~300ms.
- **Source:** Parent feedback

### Responsive Behavior
- **Decision:** Uniform scaling across all devices.
- **Detail:** Same layout, same proportions on phone, tablet, desktop. Touch targets always 48px+ CSS. Scales to fit viewport while maintaining scatter distribution.
- **Source:** Parent feedback

### Color Palette
- **Decision:** Balanced mix of saturated primaries + softer tones.
- **Detail:** Primary colors (red, blue, yellow, green, purple) + accent pastels for variety. Vibrant but not harsh. Exact colors TBD in design execution.
- **Source:** Parent feedback

### Typography & Microcopy
- **Decision:** Minimal text; sounds and visuals lead.
- **Detail:** No persistent UI text. Success feedback delivered via sound + vibration + visual only. Optional "Great job!" on round end (minimal, encourage without text overload).
- **Source:** Parent feedback

### Rapid Taps Handling
- **Decision:** Lock to one — extra taps ignored/handled gracefully.
- **Detail:** Once a shape is selected, it remains selected until a silhouette is tapped (match attempt) or a *different* shape is deliberately tapped (switch selection). Rapid taps on other shapes are ignored; no error, no feedback, just locked.
- **Source:** Parent feedback + design best practice for 4-year-old mental model

### Edge Cases
- **Screen rotation:** Adapt seamlessly. If tablet rotates mid-round, layout reflows but game state persists (shape selection, matches so far).
- **Accidental overlaps:** Shapes have minimum 8–12px spacing to prevent accidental overlaps. If unavoidable (rare), tap the topmost shape; silhouettes are easier to target (larger visual space).
- **Mute toggle:** Visible but not intrusive—top-right corner icon, simple toggle.
